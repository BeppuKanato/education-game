# 素材

- `public/assets/lab-room.png`：本プロジェクトのために画像生成した、人物・UIを含まないオリジナル背景。
- `public/assets/researchers.png`：本プロジェクトのために画像生成した4人のオリジナル人物。元画像を保持し、Phaserのテクスチャフレームで各人物を参照。
- `public/fonts/NotoSansJP.woff2`：Google FontsのNoto Sans JP。可変フォントの全グリフをWOFF2形式へ変換。SIL Open Font License 1.1。ライセンス原文は同じディレクトリの`OFL.txt`。
  - 元フォント：https://github.com/google/fonts/tree/main/ofl/notosansjp
- UI図形・照準・アイコン：コードで描画。
- 効果音：Web Audioで作る短いオリジナル合成音。ボイス・BGMは未収録。

UIイメージ画像をそのまま背景として使用していません。文字・指摘箇所・資料・ボタンは実行時に描画します。ダンガンロンパ等の既存作品のキャラクター、音声、画像、ロゴは使用していません。
